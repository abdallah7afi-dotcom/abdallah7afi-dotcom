### 🚀 Featured Project

#### 🔋 [EV-Charge Navigator](https://github.com/abdallah7afi-dotcom)
A commercial-grade mobile application designed to help EV drivers in Saudi Arabia locate, navigate to, and review charging stations.

- 📍 Live map with **29+ Riyadh charging stations**
- 🧭 Real-time **GPS navigation & route planning**
- 🔐 Secure **Firebase authentication**
- ⭐ Community-driven **reviews & ratings system**
- 🧠 Smart station recommendation logic

*Built as a Final Year Project with a strong focus on real-world usability and commercial readiness.*
